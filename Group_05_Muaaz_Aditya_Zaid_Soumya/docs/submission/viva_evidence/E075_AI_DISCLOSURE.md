## One real AI error from this drafting
First hysteresis design: exit margin only (a tier is left only 2.0 m past its threshold). The AI expected this to
cut false alarms. The demo run showed it barely did. False tier-3 alarms over 100 seeds, noise on, skirt path,
interior: 1948 with hysteresis off, 1650 with the exit margin on (exterior: 1804 versus 1549). Crossing path
interior: 632 versus 417. Reason: an exit margin only suppresses re-entry after a first false entry; it does nothing
about the first noisy reading that crosses the line. Fix: a tier-3 dwell (5 consecutive inside readings before
tier 3 is raised, tier 2 shown meanwhile). After the fix the same demo shows 1 false alarm per 100 skirt runs in each
scene (interior crossing 3, exterior crossing 5). No test failed: the error was caught by reading the demo table,
and the final table is in `results/geofence_noise_demo.txt`. The cost of the fix is a delay of 4 readings
(0.4 s at 10 Hz) before a genuine breach is reported as tier 3, which is a safety trade-off you should be able to explain.
