2.1 Regions inside the shared control file

# ======================================================================
# >>> E051 ADITYA -- COMPUTER VISION  >>>
# ======================================================================
    def detect_intruder_hsv(self, rgb_frame): ...
    def inverse_pinhole_projection(self, u_px, v_px, uav_pos, ...): ...
# ======================================================================
# <<< E051 ADITYA <<<
# ======================================================================

Lines between a member’s markers are theirs. Lines outside any region — imports, the class constructor, main() — and the marker lines themselves belong to E043 as shared plumbing. The gate reads these markers from both the base and the branch version of the file, so a change that moves a marker is caught too.

The rule that protects everyone’s viva marks Muaaz reviews, requests changes and merges — he does not write inside anyone else’s region. If a member is stuck, the fix is a pairing session or a smaller scope, never a commit under the wrong name. The viva asks each student to modify and re-run their own code live.

6Working in Parallel

Nobody waits for anybody, because every interface already exists in a form you can code against:

  • Aditya — the loop already renders cam_alpha/cam_bravo at 640×480 and calls detect_intruder_hsv. Until M-09 lands, render frames yourself with mujoco.Renderer from the same model.
  • Zaid — self.substation_bounds is already read from the model. The FSM and polygon test can be developed against plain coordinates in tests/test_e075_*.py with no detector at all.
  • Soumya — the CSV schema is fixed and analytics/runs/bench_smoke.csv already has real rows. Write the economics against those columns now; it picks up new data automatically.
The daily test Ask each member “what are you waiting for?” If the answer names a person, the missing stub or fixture for that dependency is the highest-priority task on the team.

14Definition of Done

  1. The FR’s verification passes and its status in PRD §8 is updated in the same PR.
  2. Every changed line lies in the author’s region or owned files (gate passes).
  3. A test fails if the feature regresses.
  4. Any number it produces lands in a CSV via run_benchmark.py.
  5. Constants are named, carry units and cite a source.
  6. The author can explain every line, unprepared, in two minutes.
  7. Merged to main, and the evening reference flight is green afterwards.

16Viva Preparation

The guide supplies model answers. Two of Muaaz’s are contradicted by measurement, and saying so with evidence is a stronger answer than repeating them.

MemberLikely questionAnswer grounded in this repository
E043Does your APF guarantee d ≥ 2.5 m at the sector hand-off?Not on its own. Measured head-on at 6 m/s each: 0.40 m — contact. The closing energy is 48.6 J; the field can only absorb it by d = 0.26 m, and rotor thrust saturates long before the force “diverges”. Separation therefore comes from altitude layers, a closing-speed governor and a right-hand sidestep, with APF as the inner layer — 3.29 m in the same test.
E043How does yaw control work with four upward thrusts?Through rotor drag torque: opposite pairs spin opposite ways, encoded as ±kQ in each rotor’s gear vector. The scaffold had kQ = 0, which gives no yaw authority at all.
E043Why read inertia carefully?MuJoCo reports it in the principal frame, reordered here so Izz comes first; using it raw would control roll with the yaw inertia.
E051Derive the inverse pinhole projection — when is it valid?Only for a level, North-aligned camera. In flight the tilt is 7° median and 28° at p95, giving 11–13 m error at p95; the ray must be intersected with the ground using the full camera pose.
E051Would HSV work on a real person?No — the avatar is red by design. The scene’s red tempo cabs and signal lamps measure how quickly colour-only detection produces false alarms.
E075How does hysteresis prevent chatter?Enter at 0.5 m inside, clear only 2.0 m outside for 3 frames; demonstrated by a test walk along the border.
E075How is blind-spot percentage computed?Wall-line samples ray-cast from each camera with tree and building occlusion — not a typed-in figure.
E077Is a 6.21× speedup real?It was a placeholder. The measured value depends on the comparator definition, which is stated in the paper.
E077How is payback computed without currency?Normalised to the guard-only budget ≡ 1.00, inputs from the CSV, reported as a band with the break-even point.
